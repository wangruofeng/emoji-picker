# Emoji 丰富详情面板与 Modal 设计

## 目标

参考 `unicode-symbol-picker` 的详情层级，同时升级 Emoji 选择器的右侧详情面板与放大 Modal。用户应能在不离开当前页面的情况下查看完整编码、Emoji 属性、组合码点结构，并执行复制、收藏和分享操作。

## 范围

- 右侧详情面板增加紧凑的 Emoji 属性摘要，并保留现有编码与肤色变体。
- 现有纯预览 `zoomOverlay` 升级为完整详情 Modal。
- 面板与 Modal 共用同一份详情数据模型。
- 支持普通 Emoji、肤色修饰、性别组合、ZWJ 序列、表现选择符以及 Emoji 17 图片兜底。
- 不引入新的远程数据接口，不重构 Emoji 主数据，不修改搜索、收藏和最近使用的数据格式。

## 信息架构

### 右侧详情面板

1. 预览区：Emoji、中英文名称、收藏按钮和关闭按钮。
2. 编码信息：Unicode、UTF-8、HTML 十六进制、CSS content、JavaScript 转义。
3. Emoji 属性摘要：分类、码点数量、组合类型、肤色、性别、表现形式和数据标准。
4. 肤色变体：沿用现有逻辑，仅在适用时出现。
5. 点击 Emoji 预览打开完整 Modal。

### 完整详情 Modal

顶部 Hero 展示大尺寸 Emoji、中英文名称、分类标签、版本标签和收藏按钮。主体采用双栏：左栏为编码信息，右栏为 Emoji 属性。码点拆解和关键词位于双栏下方的整行区域，底部提供复制 Emoji 与复制分享链接操作。

编码字段：

- Unicode 十六进制码点
- Unicode 十进制码点
- UTF-8 字节
- HTML 十六进制实体
- HTML 十进制实体
- CSS content
- JavaScript 转义

Emoji 属性字段：

- 分类
- 码点数量
- 组合类型：单体、修饰序列或 ZWJ 序列
- 肤色：无或具体修饰符列表
- 性别：中性、男性、女性或未指定
- 表现形式：Emoji、包含 `FE0F` 或默认表现
- 渲染来源：系统原生或 Noto Emoji 图片兜底
- 数据标准：Unicode Emoji 17.0
- 新增版本：仅 `EMOJI_IMAGE_FALLBACK` 中能确认的 Emoji 17 项显示“Emoji 17.0”；其他项目不推测版本

## 码点拆解

`buildCodePointParts(value)` 按 Unicode 码点遍历完整字符串，每个码点生成一个独立条目：

- 可见字符；不可见控制符使用缩写标记
- `U+XXXX`
- 十进制值
- 角色说明

角色识别规则：

- `U+200D`：ZWJ 连接符
- `U+FE0F`：Emoji 表现选择符
- `U+1F3FB–U+1F3FF`：肤色修饰符，并显示本地化肤色名称
- `U+2640` / `U+2642`：女性 / 男性符号
- 其他码点：基础 Emoji 或组合组件

码点拆解不改变原始字符串，也不影响复制结果。

## 数据与组件边界

新增纯数据函数 `buildEmojiDetailModel(item)`，输出：

- 编码对象
- Emoji 属性对象
- 码点拆解数组
- 分类、关键词和版本标签
- 渲染来源

右侧面板和 Modal 只消费该模型，不各自推导字段。图片渲染继续复用 `makeEmojiNode()` 和 `setEmojiDisplay()`；复制继续复用 `copyAndToast()`。

## 交互

- 点击右侧 Emoji 预览或键盘按 `Enter` / `Space` 打开 Modal。
- 点击遮罩、关闭按钮或按 `Escape` 关闭 Modal。
- 打开时记录当前焦点、锁定页面滚动并将焦点移到关闭按钮。
- Modal 内 `Tab` / `Shift+Tab` 循环于可交互元素；关闭后恢复原焦点。
- 每个编码字段具有独立复制按钮。
- “复制 Emoji”复制原始完整序列。
- “复制分享链接”复制带 `?q=<emoji>` 的当前站点绝对 URL。
- 收藏按钮与右侧面板、网格状态保持同步。

## 响应式布局

- 桌面 Modal 最大宽度约 `820px`，最大高度约 `88vh`，内部滚动，主体为双栏。
- 小于 `760px` 时 Modal 变为全屏单栏，编码、属性、码点拆解和关键词依次排列。
- 移动端右侧详情继续使用底部抽屉形式并允许内部滚动。
- 码点拆解使用自动换行卡片，长 ZWJ 序列不得产生横向页面滚动。

## 错误处理

- Noto 图片加载失败时沿用明确的不可用占位状态，不回退为可能产生乱码的原始字形。
- 缺失属性显示“—”或隐藏可选字段，不构造不可靠的版本信息。
- Clipboard API 失败时沿用现有复制失败提示。
- Modal 始终显示原始 Unicode 编码，即使视觉图片不可用。

## 无障碍

- Modal 使用 `role="dialog"`、`aria-modal="true"` 和标题关联。
- 关闭、收藏、复制按钮具有本地化 `aria-label`。
- Emoji 图片具有原始 Emoji 作为替代文本；装饰性重复预览根据上下文设为隐藏。
- 码点拆解使用语义化列表，键盘无需进入每个只读条目。

## 验证

浏览器验证至少覆盖：

1. 普通 Emoji `👱‍♀️`：系统原生渲染，属性正确。
2. 肤色与性别组合 `👯🏾‍♂️`：图片正常，编码保留 `FE0F`，拆解正确。
3. Emoji 17 芭蕾舞者 `🧑🏿‍🩰`：图片兜底与版本标签正确。
4. 长双人物 ZWJ 序列 `👩🏻‍🫯‍👩🏼`：码点卡片完整换行。
5. 编码复制、Emoji 复制、收藏同步、分享链接、遮罩关闭、`Escape`、焦点循环和焦点恢复。
6. 桌面双栏和移动端单栏均无裁切、溢出或滚动陷阱。
7. 页面无相关控制台错误，内联脚本语法与 `git diff --check` 通过。

## 非目标

- 不为旧 Emoji 推断精确的首次加入版本。
- 不增加相似 Emoji 推荐算法。
- 不下载或内置完整 Noto Emoji 资源包。
- 不改变点击网格后自动复制 Emoji 的现有行为。
