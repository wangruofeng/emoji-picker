# Logo 与 Favicon 重设计

## 目标

将现有“蓝紫渐变方块 + 系统 Emoji”标识替换为原创、友好、有趣的「跳跳心」标识，并在页面 Header、浏览器 favicon 与 PWA manifest 中保持一致。

## 视觉设计

- 主体为暖橙色圆形笑脸，不使用平台 Emoji 字形。
- 两颗粉红爱心分别位于左上与右上，一高一低，形成跳跃动势。
- 面部采用「三条柔弧」：两条闭眼弧线和一条微笑弧线，全部使用圆头描边。
- 使用纯色而非渐变，保证缩小后的辨识度与资产使用一致性。
- Header 保留现有“Emoji 选择器”文字与副标题，不扩展为全站配色重构。

## 资产与使用

- `logo.svg`：完整图标资产，提供可复用的 72 × 72 viewBox。
- `favicon.svg`：小尺寸优化版本，线条略粗，继续被 HTML 与 PWA manifest 引用。
- Header 内嵌同构 SVG，避免外部资源加载失败影响首屏品牌显示。
- Logo 的可访问名称为“Emoji 选择器 Logo”，装饰性内部路径不重复暴露给辅助技术。

## 验收标准

- Header 不再显示系统 😀 字形或蓝紫渐变方块。
- `logo.svg` 与 `favicon.svg` 均为有效 XML/SVG。
- favicon 在 16px 与 32px 下仍能辨认圆脸、三条柔弧和两颗爱心。
- manifest 继续引用存在的 favicon 资产。
- 页面原有搜索、复制、主题切换和多语言逻辑不受影响。
