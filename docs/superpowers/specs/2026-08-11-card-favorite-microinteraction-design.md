# Emoji 卡片收藏微动效

## 目标

为 Emoji 卡片右上角的收藏按钮提供明确、轻量的点击反馈，不改变收藏数据、卡片尺寸或详情区域的交互。

## 交互

- 收藏：星标以约 180ms 轻微弹出后稳定为已收藏状态。
- 取消收藏：星标以约 180ms 轻微回缩后恢复未收藏状态。
- 动效仅在卡片右上角的 `.fav-star` 触发；详情面板与详情弹窗按钮保持现状。
- 系统启用“减少动态效果”时禁用该动效。

## 实现与验证

- `toggleFav()` 在同步卡片星标状态时添加一次性动效类，并在动画结束后移除。
- CSS 只为该类定义变换动画，不影响现有 hover 状态或 `on` 状态。
- 验证收藏和取消收藏均更新状态，动效类会清理，且减少动态效果下不播放。
